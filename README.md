# ppSR集成工具

本地角色、光锥、遗器、怪物与关卡配置管理工具，提供私服启动、配置同步和软件签名更新。

## 软件更新

已安装并配置签名更新的预览基础包，可在 **版本更新 → 软件更新 → 检查软件更新** 下载新版。校验完成后点击 **安装已验证更新**，保存编辑并正常退出；下次打开使用新版。

- 玩家下载公开更新无需 GitHub 账号或令牌。
- 更新清单使用 Ed25519 签名；下载包和每个文件使用 SHA-256 校验。
- 配置库、草稿、游戏与服务器文件、账号数据、日志和备份独立保留。
- 只接受明确支持当前来源版本的更新包；安装失败保留回退文件。

**当前 Release 的 update.zip 是更新包，不是首次安装包。** 它适用于本项目已接入签名更新的 `0.2.0-preview` 基础环境。当前仍为开发预览版；自带 Python、Qt、Node 和全部依赖的独立首次安装包尚未发布。不要将更新包解压到正式服或游戏目录。

## 发布附件

- `latest.json`：签名更新清单，供客户端读取。
- `update.zip`：软件更新文件。
- `publisher-public.pem`：发布者公钥副本，便于核验；客户端预置可信公钥，不会从下载内容自动替换信任。

固定更新入口：`https://github.com/Tangdusama/ppsr-integrated-tool/releases/latest/download/latest.json`。
