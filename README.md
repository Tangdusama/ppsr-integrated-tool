# ppSR集成工具

本地角色、光锥、遗器、怪物与关卡配置管理工具，提供服务器启动、配置同步及签名更新。

## 下载

前往 [0.3.3 下载页面](https://github.com/Tangdusama/ppsr-integrated-tool/releases/tag/v0.3.3)。新玩家可直接安装最新版，现有用户也可在软件内更新。支持 Windows 10/11 64 位。

- **[Online-Setup-x64.exe（轻量版）](https://github.com/Tangdusama/ppsr-integrated-tool/releases/download/v0.3.3/ppSR-Integrated-Tool-0.3.3-Online-Setup-x64.exe)**：约 296 MB，内置 Python、Qt、Node 和所有必要依赖。首次启动从 GitHub 下载约 1.49 GB 图片素材，提供下载进度、暂停续传、失败重试和签名/哈希校验。完成后素材保存在本地，后续不重复下载。

- **[Setup-x64.exe（完整版）](https://github.com/Tangdusama/ppsr-integrated-tool/releases/download/v0.3.3/ppSR-Integrated-Tool-0.3.3-Setup-x64.exe)**：约 1.77 GB，已包含全部素材，适合首次使用时不方便联网的电脑。

两种版本安装后的功能相同。轻量版减少安装程序本身体积，首次使用仍需要下载完整图片资源。软件不会携带发布者的账号、路径、密码或玩家配置，也不包含游戏客户端与 ppSR 服务端。

## 首次使用

在「启动与连接」自动扫描或手动选择自己的服务端和客户端，保存后重启工具。扫描会排除官方客户端；不要把工具安装到游戏目录。首次登录游戏仍由玩家完成。

## 软件更新

每次启动自动检查软件新版本，确认后才下载。勾选“此版本不再提示”只忽略当前新版，更高版本仍会提示。也可随时进入「版本更新 → 软件更新 → 检查软件更新」。下载并验证后点击安装，保存编辑并正常退出；下次打开使用新版。公开下载无需 GitHub 账号或令牌。

软件更新与素材下载都验证 Ed25519 签名、SHA-256 和文件路径。更新保留配置库、编辑草稿、安装设置、日志与备份；普通代码更新不会重复下载全套素材。依赖或运行环境升级时使用完整安装程序。

0.2.x 属于开发基础环境，迁移到 0.3 独立版需要使用安装包。`update.zip`、`latest.json`、`assets.zip` 与 `assets-manifest.json` 由软件自动读取，无需玩家手动解压。

当前软件版本为 0.3.3。轻量版和完整版均经过独立目录安装、运行环境、接口及快捷方式检查。遇到问题时可在“错误日志”导出 TXT，反馈错误代码和操作步骤。

## 致谢

本地编辑功能基于 Firefly SRTools，保留上游标识与相关说明。组件许可证包含在安装目录。此仓库仅用于集成工具发布，不提供游戏包体、服务端程序、服务器登录密码或用户配置。

## 0.3.3 更新内容

三类更新增加进度与预计剩余时间；改进 HDIFF 结束等待、目录占用和重复包处理。修复 srtool 资料更新，补查间隔版本，默认保留上游移除的旧条目。更新内置资料，修复角色、怪物图片和强化角色的技能、星魂显示，并保留“尘世卷中”名称。五类关卡配置通过隔离服务器同步检查。

已有用户的软件内更新包约 11.2 MB，支持从 0.3.0-preview、0.3.1 和 0.3.2 升级。新玩家可选择内置运行环境的轻量版或完整版。
