# ppSR集成工具 1.0.2

## 客户端语言

- 在「版本更新 → ppSR 与客户端」的检查与升级下方新增「客户端文本语言」，可选择简体中文或 English。
- 退出客户端后应用，下次启动生效；语音语言保持原样。
- 客户端更新时自动处理语言文件的还原与恢复，保留 HDIFF 来源和目标校验。

## 遗器编辑

- 所有角色的遗器编辑统一为三列：左侧主设置、中间竖排部位、右侧竖排四条副词条。
- 部位栏保留遗器图标，副词条区域收窄，控件与文字对齐；浅色和深色主题沿用软件原有样式。

## 角色图片

- 修正艾莲、耀嘉音第 3 和第 5 星魂误用技能符号的问题，改为对应星魂图片。
- 素材更新后刷新桌面图片缓存，保留已有草稿和设置。

## 快速 SL

- 增加 4.7.51 客户端的接口与回放位置适配，加载前核对客户端对应信息。
- 回放发生行动、随机数或状态差异时停止并保留诊断，可在「错误日志」导出后到 GitHub 反馈。
- 4.7.51 下的四倍回档和续战仍需实战测试；遇到卡停或差异提示，请附上队伍、关卡、操作步骤和导出的错误日志。

## 安装与升级

- 已有用户可在「版本更新 → 软件更新」检查并安装 1.0.2，保留角色、怪物、场地配置及设置。
- 新玩家可选择 Online 轻量安装包或完整安装包，两者均内置运行环境。轻量版首次运行下载基础图片，完整包内置图片。
- `update.zip` 供软件内部更新使用，不能作为首次安装包。
