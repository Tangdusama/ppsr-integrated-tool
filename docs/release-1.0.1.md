# ppSR集成工具 1.0.1

本次更新改进版本检测、下载和启动流程，并新增角色专属效果开关。

## 角色配置

- 按 4.7.51 补充艾莲、耀嘉音及光锥「雨天请勿排班」「闪亮如她」，提供角色技能、行迹、星魂和本地图片。新角色使用原生竖向头像，光锥使用对应图标。
- 修复更新后桌面窗口仍显示旧图片的问题；素材变化时刷新图片缓存，保留草稿和登录状态。
- 补充异相仲裁「喜笑与悲泣」，以及新版混沌回忆、虚构叙事、末日幻影；包含关卡波次、场地效果和怪物数据。
- 怪物配置补充堕神之血•亚婆离及其他新增变体；保留已有配置与旧条目。已有资料更新到更高版本时，优先使用新资料。
- 在秘技与强化开关下方显示角色可控制的专属效果，支持遐蝶「月茧之庇」、银狼 LV.999「999安全卫士」和星神★阿哈「阿哈时刻在」。
- 没有对应效果的角色不显示此区域。开关使用实际技能名称，支持读取和保存服务器当前设置。

## 版本更新

- 修复 Discord 频道读取卡住或回调失联的问题，读取超时后提供明确提示。
- 进入公告提供的下载链接，按实际文件名识别客户端补丁、完整客户端和服务器版本，避免公告文字或引用旧消息造成识别错误。
- HDIFF 仍逐版本升级；整包与补丁分开识别，安装前后继续校验源文件、补丁清单及目标文件。
- 下载齐全后才开始安装；先下载较小的服务器包，再下载客户端补丁。下载站过载时保留已下载文件，便于稍后继续。
- 更新服务器时自动补齐仓库技所需的角色归属字段，保留原有开关和角色配置，修复升级后服务器启动退出的问题。
- 修复服务器安装后的版本记录，让更新检测与实际安装版本保持一致。

## 启动

- 本地界面端口被其他软件占用时自动选择可用端口，避免工具提示本地服务启动失败。

- 安装目录检查会列出缺失的客户端组件，不再笼统提示路径或权限问题；支持资源管理器复制的带引号路径。扫描仍排除正式客户端。
- 新版服务器和客户端不再因历史固定哈希不匹配而被拒绝启动；使用当前组件尝试运行，并提示实际加载失败或启动后退出的原因。

## 安装与升级

- 已安装 1.0.0 的玩家可在「版本更新 → 软件更新」检查并安装。
- 新玩家使用 Online 轻量安装包或完整安装包。轻量版首次启动需要联网下载图片素材；完整包内置素材。
- 更新保留已有角色、怪物、场地配置和设置。客户端及服务器更新仍由「版本更新」中的对应功能单独执行。
- 快速 SL 沿用 1.0.0 的回放模块；本次没有调整其战斗回放逻辑。目前未适配 4.7.51 客户端，加载可能提示 SF-REPLAY-032；正常启动与配置编辑可继续使用。
